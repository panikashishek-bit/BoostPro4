# База знаний администратора

Это то, что бот-администратор отвечает **клиентам**. Всё в этой папке считается публичным.

## Правило безопасности

Сюда попадают **только** факты, которые не жалко показать любому человеку в переписке: услуги, цены, часы работы, адрес, правила записи.

Сюда **никогда** не попадают: ключи, токены, пароли, содержимое `.env`, устройство приложения и базы, адреса API, имена и телефоны клиентов, внутренние договорённости с мастерами. Техническая дока живёт отдельно — в `../docs/` — и наружу не показывается.

## Что здесь лежит

| Файл | О чём |
|---|---|
| `salon.md` | Название, адрес, часы работы, оплата, парковка |
| `services.md` | Услуги: что входит, цена, длительность |
| `masters.md` | Мастера и кто какие услуги делает |
| `booking.md` | Как записаться, перенос, отмена, опоздание, приход без записи |
| `care.md` | Сколько держится результат и как ухаживать |

## Откуда бот берёт факты

Свободное время, актуальные цены и список услуг бот берёт **из API приложения** — там живая база. Эта папка нужна, чтобы отвечать на вопросы, которых в базе нет: как добраться, чем платить, можно ли с ребёнком.

Если цена в `services.md` разошлась с ответом API — **верна цена из API**, а файл нужно поправить.

Чего нет ни здесь, ни в API — бот честно говорит, что не знает, и даёт телефон салона. Выдумывать нельзя.

## ⚠️ Что заменить перед реальным запуском

Проект учебный, поэтому часть фактов придумана. Заменить на настоящие:

- [ ] `salon.md` — название, адрес, телефон, ориентир, парковка
- [ ] `booking.md` — правила отмены и опоздания (сейчас мягкий вариант без штрафов)
- [ ] `booking.md` — ответ про детей (сейчас: от 7 лет, по цене взрослой стрижки)
- [ ] `care.md` — сроки носки и рекомендации по уходу: сверить с мастерами
