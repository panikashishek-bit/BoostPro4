# Командные правила агента — рабочая папка Boost Pro

> Регламент твоего «штаба». Агент читает эти правила автоматически и работает по ним весь курс, как дисциплинированный сотрудник. Правила лежат в корне проекта и управляют именно им.

## Правила работы с репозиторием и проектом
1. **Документация в ногу с кодом.** Перед сохранением проверь, что изменения в коде отражены в `./docs/`.
2. **Сначала подтяни свежее — не затри чужое.** Перед отправкой в общий репозиторий (push): сначала `git fetch` + `git pull --rebase`; убедись, что не расходишься с общим репозиторием и не затираешь чужие изменения.
3. **Короткие понятные коммиты.** Сохраняй изменения небольшими осмысленными порциями с понятным сообщением.
4. **Никогда не сохраняй секреты.** Пароли, токены, ключи — только в `.env` (в `.gitignore`); в репозиторий идёт `.env.example` со списком имён без значений. В чат агенту секреты не передавать.
5. **Файлы проекта — внутри этой папки.** Материалы курса (папки воркшопов) не трогай и в репозиторий проекта не добавляй.
