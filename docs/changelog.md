### Added
- Второй сотрудник в штабе (`public/index.html`): слой `overlay_assistant.png` поверх холста рядом со слоем администратора. Подпись под заголовком обновлена — в штабе двое, два стола свободны.

- Выгрузка журнала обращений в Markdown: `npm run export:clients` в `bot_administrator/` собирает `project/clients-export.md` из таблицы «Клиенты». Только чтение таблицы, повторный запуск перезаписывает файл. Сам файл в git не едет — в нём имена и телефоны клиентов, а репозиторий публичный.

- Первичная документация проекта: `docs/architecture.md` (состав, связи частей, ключевые технические решения, ограничения) и `docs/context.md` (пользователи, задачи клиента, ценность, границы продукта). Код не менялся — описано то, что уже есть.

### Changed
- `docs/architecture.md`: раздел про ключ служебного аккаунта на сервере приведён в соответствие с кодом — ключ приходит переменной `GOOGLE_SA_KEY`, а не монтированием тома.
